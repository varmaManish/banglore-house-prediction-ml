ABOUT THE PROJECT

ARCHITECTURE OVERVIEW

◦ MISSION BRIEF

HouseAI is an advanced real estate price prediction system engineered for the Bangalore property market. Using regression algorithms trained on thousands of listings, it delivers accurate valuations in milliseconds.

◦ MODEL PARAMETERS

The model processes four key variables — location, square footage, bathroom count, and BHK configuration — to generate a market value estimate aligned with current Bangalore real estate trends.

◦ TECH STACK

  • Python 3.11 — Core Language
  • Flask — Web Framework
  • Scikit-Learn — ML Engine
  • NumPy / Pandas — Data Layer
  • Bootstrap 5 — UI Foundation

◦ PERFORMANCE METRICS

  • Algorithm — Linear Regression
  • R² Score — 0.847
  • MAE — ₹4.2 Lakhs avg error
  • Training Set — 8,000+ records
  • Inference Time — <50ms
DATA PIPELINE

◦ HOW IT WORKS

Raw listing data from Bangalore is collected, cleaned, and preprocessed to remove outliers and anomalies. Features are one-hot encoded for location data, and the final model is serialized using joblib for fast production inference. Every prediction request is processed server-side in real time with no caching.
